# Security policy

## Reporting a vulnerability

Report a security issue privately through GitHub: open this repository's **Security** tab and choose **Report a
vulnerability**. Please do not open a public issue or pull request for it.

Include:

- the `@unrlzd/sdk` version (`npm ls @unrlzd/sdk`),
- what you found and what it lets someone do,
- the steps or code to reproduce it.

## Scope

- `@unrlzd/sdk` and the example in this repository: report here.
- The trading account and factory contracts: report privately on
  [UNRLZD/contracts](https://github.com/UNRLZD/contracts/security).

## Supported versions

Security fixes are released as a new version of the latest release line. Upgrade to the newest version to get them.

## Security model

What a device key can and cannot do, and what the SDK checks before it signs, is on the
[Security model](https://docs.unrealized.trade/developers/security/) page.
